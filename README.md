# People Ops Skills for Claude Code

Modern hiring tools for People leaders — built on the 8 Key Relationships framework.

## What's included

### `/work-experience-and-interview`
Generates a complete **Work Experience Description** (a modern alternative to traditional job descriptions) + a **full structured interview plan** including:
- All 8 relationship sections written in your company's voice
- Recruiter screen, hiring manager, and competency interview questions
- Level-calibrated questions (IC1 through M8)
- Optional values interview round with tailored questions
- Competency scorecards with 1–4 rating scale
- Role exercise brief
- Master candidate scorecard

Works with Claude Code, Codex CLI, Cursor, and Gemini CLI.
